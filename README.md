# 入境游服务编排器

省级入境游服务平台的编排后端。把护照核验、通信卡、外卡充值、酒店入住、景区容量与离境退税串成一次连续旅程，用追加式领域事件关联旅客最小身份、同行组、语言与过敏原偏好、行程提案、预订保留、支付令牌、酒店资格、通关与退税记录。

## 模块

- `src/event-store.js`：追加式事件存储，编排链路的唯一事实来源。
- `src/events.js`：事件构造（版本号按聚合自动递增）。
- `src/journey.js`：六步旅程编排投影，旅客视图与客服视图。
- `src/booking.js`：预订保留的确认前重校验与替代方案生成。
- `src/payments.js`：支付令牌台账与一次性凭证台账。
- `src/disclosure.js`：按用途的最小身份披露与客服脱敏。
- `src/translation.js`：多语内容溯源（来源、语言版本、人工纠错）。
- `src/records.js`：酒店资格、通关、退税等旅程记录器。
- `src/audit.js`：监管审计台账（数据共享、资金、退税）。
- `src/domain.ts`：领域类型定义（事件信封、聚合、步骤视图、披露用途）。
- `contracts/domain.schema.json`：事件信封的 JSON Schema 契约。

## 行为保证

- **幂等与断网补报**：事件按 `event_id` 去重，内容冲突拒绝；同一聚合内版本连续递增，乱序补报被拒并提示补全。资金动作与预订确认按 `operation_id` 幂等，重复回调返回首次结果，不重复扣款、不重复确认。凭证核销一码一次，离线重发同一 `redemption_id` 幂等重放。
- **跨时区截止**：授权截止等时刻一律按 ISO 串解析为绝对时刻比较，与本地时区无关。
- **最小披露**：护照字段按用途只给必要合作方（`src/disclosure.js` 的 `DISCLOSURE_RULES`），未登记用途一律拒绝；客服只见脱敏身份即可接续问题。每次披露写入审计事件，事件只记字段名不记字段值。
- **翻译溯源**：译文保留来源语言、原文与引擎类型；机器翻译永远不得标记为官方事实；人工纠错产生后继版本，旧版本保留可查。
- **确认前重校验**：预订确认前重新向合作方校验价格与容量，漂移或不足即拒绝确认并记录；部分失败时在剩余预算与交通可行性约束下生成替代方案。
- **监管审计**：数据共享、资金、退税三类台账均可从事件流重建，并检查链路完整性（扣款须有授权、退税完成须有申报）。

## 领域边界

事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正应产生后继记录。涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。
